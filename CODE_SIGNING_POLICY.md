# Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

microProject publishes release artifacts built only from the public repository https://github.com/tetsuji16/microProject, via GitHub Actions. Only binaries built from this repository's own source code and build scripts are submitted for signing. No third-party or private binaries are signed with this certificate. Each release requires manual approval by an Approver before signing. All signed binaries carry the product name "microProject" and the same product version within each build.

## Roles

- Authors / Reviewers: repository collaborators of tetsuji16/microProject
- Approver: Tetsuji Kato (tetsuji16), repository owner

All team members use multi-factor authentication for GitHub and SignPath access.

## Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.
