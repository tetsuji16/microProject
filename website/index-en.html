Plan tasks and schedules in one desktop view.

microProject is a desktop project planning tool that combines a hierarchical task table with a Gantt chart. Review dates, dependencies, progress, and assigned work on the same timeline. Organize a WBS outline while seeing milestones, parallel work, and successor links.

Create and save projects, import and export files, print, or create PDF output from the desktop app. Windows downloads include a self-contained installer and portable ZIP with Java included.
