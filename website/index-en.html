Plans, schedules, and progress in one desktop view.

microProject is a desktop project planning application that combines a hierarchical task table with a Gantt chart. Edit a WBS outline and review dates, dependencies, resources, and progress on the same timeline.

It offers a Microsoft 365-style ribbon, Microsoft Project-style shortcut keys, Critical Chain (CCPM) buffer management, printing, and PDF output. The Java runtime is bundled, so it runs right after download.

Features

Task table and Gantt in sync

Edit the WBS task hierarchy and see dates, links, milestones, and progress on the timeline without switching views.

Scheduling

Dependencies, calendars, constraints, baselines, and resource assignments drive automatic rescheduling.

Critical Chain (CCPM)

Preview and apply resource-aware leveling, review the network, and track project and feeding buffer consumption.

Familiar Office-style UI

Ribbon, Microsoft Project-style shortcuts, Undo/Redo, printing, and PDF output.

File formats

  • .mpo — native format and default save format; files from earlier releases still open.
  • .mpp — open Microsoft Project files (writing MPP is out of scope; save as .mpo).
  • Project XML and XLSX — open and save. MPX — open only.
  • .pod — ProjectLibre's standard format; open and save, but CCPM settings are not stored (use .mpo).
microProject is being built through clean-room implementation. Compatibility with the standalone Microsoft Project desktop application is a goal that is not yet achieved; see the compatibility roadmap. Cloud services (Project Server, Project Online, Planner) and VBA/COM/Office add-ins are out of scope.
