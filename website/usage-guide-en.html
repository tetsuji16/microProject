microProject User Guide

For the current stable release and implementation (October 12, 2026). This guide covers basic task table, Gantt, and CCPM workflows on Windows. Linux x64 and macOS Apple Silicon packages are planned for future releases. Full compatibility with Microsoft Project is a development goal; every operation and file format is not guaranteed to be compatible.

1. Download, launch, and save

  1. Choose the latest stable release on the downloads page. There is no beta release. Run the MSI installer, or extract the Portable ZIP and launch microProject.cmd (or microProject.exe). Java is included.
  2. Press Ctrl+N to create a project and set its name and start date. Open an existing file with Ctrl+O.
  3. Save with Ctrl+S. Choose .mpo (MPOF) to preserve CCPM settings and history. The .pod format does not store CCPM extensions.
  4. For your first use, try a copy or sample project, then reopen the saved file to check its contents.

Open existing MPP, XML, POD, and other files with Open. Import and export support varies by format; keep a separate copy of source files you may update.

2. Build a plan in the task table

  1. In the task table on the left of the Gantt view, edit the name cell in an empty row to create a task. Use Insert to add a row and F2 to edit a cell.
  2. Enter a duration, such as 2d. Start and finish dates are calculated using dependencies, working calendars, and constraints. A zero-duration task is a milestone.
  3. Select rows to become children and press Alt+Shift+Right to indent; Alt+Shift+Left to outdent. Expand or collapse summary rows to organize the hierarchy.
  4. Select tasks in sequence and press Ctrl+F2 to link them. Press Ctrl+Shift+F2 to unlink. You can also edit links in the Predecessors column. Avoid circular links.
  5. Press Shift+F2 to review task details, dates, constraints, predecessors, and resources.

Select, edit, and delete

Select rows by their row numbers. Ctrl+Space selects a row; Shift+Space selects a column. Copy and paste with Ctrl+C and Ctrl+V; fill down with Ctrl+D. Delete removes selected items, while Ctrl+Delete clears contents. Check the selection before acting. Undo with Ctrl+Z and redo with Ctrl+Y.

Resources and progress

Add people on the Resource sheet and assign them to tasks. Update percent complete from 0 to 100%. To record a delay, update actual start and remaining duration or remaining work as well as percent complete. Record actual finish for completed tasks.

3. Review dates in the Gantt chart

The left table and right bars show the same tasks. After editing the table, review bar position, length, and dependency lines. Press Ctrl+R to recalculate.

  1. Use Ctrl+mouse wheel to change the zoom. To find a task, select it in the table and press Ctrl+Shift+F5 to scroll to it.
  2. Drag a bar to move a task; drag its edge to change duration. Adjust progress by dragging the progress portion. Verify dates, duration, and percent complete in the table.
  3. After changing dependencies or duration, review successor tasks too. Holidays, constraints, and resource calendars may adjust dates.
  4. Do not infer status from bar color alone. Review percent complete, total slack, and actual dates. The critical path uses dependencies and slack; the CCPM critical chain also considers resource constraints.

After changing a plan, check Undo/Redo and save as .mpo, then reopen the file.

4. CCPM (Critical Chain Project Management)

CCPM considers both task dependencies and competition for limited resources. It manages execution sequence and buffers, placing shared time reserves at the project end and at points where paths join.

Apply CCPM

  1. Open a project and review task dependencies, assigned resources, and working calendars.
  2. Open Project → CCPM Settings. Enable CCPM, set a project buffer percentage, and optionally select resources.
  3. Click Preview to review changed and split tasks, unresolved conflicts, and the suggested project buffer. If conflicts remain, adjust assignments or leveling options and preview again.
  4. When the result is appropriate, click Apply Leveling. This records the CCPM baseline finish date and buffer amount.
  5. Save as .mpo and reopen the project to verify the baseline, assignments, and leveling delays.

Read the network and buffers

  • Critical chain: tasks that directly determine the finish date after resource constraints are considered. Check their progress and owners first.
  • Project buffer: shared time that absorbs delays across the chain. Compare remaining time with planned time and consider recovery actions when consumption is high.
  • Feeding buffer: time that absorbs delays entering the chain from noncritical paths. Review the incoming tasks together with remaining buffer.

Track delays and buffer history

Percent complete alone does not describe a delay. Update actual start and progress, then enter a realistic estimate in Remaining Duration or Remaining Work. Percent complete affects the Gantt completion bar; remaining duration affects successors, finish dates, and buffer consumption. Actual dates are historical and are not moved automatically by CCPM application or recalculation.

Preview after entering delays. Applying leveling immediately can make the delayed plan the new baseline and make buffer consumption harder to compare. Apply only when you intend to rebaseline. Buffer zones change with project progress.

Opening the buffer chart adds the current analysis as an observation. To exclude an erroneous point from normal charts and CSV/HTML reports, select it, choose Discard this observation…, and provide a reason. The MPOF audit record retains its ID, reason, user, and time. Undo/Redo and save/reload preserve the discard state.

After changing task durations, remaining duration, assignments, or leveling options, run Preview to refresh the analysis.
.pod is ProjectLibre's standard format and does not store CCPM extensions. Use .mpo (MPOF) to preserve CCPM settings or share projects in a folder such as OneDrive.

CCPM shortcuts: Ctrl+Alt+C opens CCPM settings; Ctrl+Shift+N opens the CCPM network; Ctrl+Shift+K opens buffer status; Ctrl+Shift+J toggles the CCPM overlay in the active Gantt view. Changing or applying CCPM settings requires a writable project.

6. Troubleshooting

Dates differ from expectations

Check predecessors, constraints, working calendars, remaining duration, and resource assignments, then recalculate with Ctrl+R. In CCPM, review conflicts in Preview.

CCPM settings are not saved

Save as .mpo. The .pod format does not include CCPM extensions. Settings cannot be changed or applied in a read-only project.

Report an issue

On GitHub Issues, include the version, reproduction steps, expected result, and actual result. A sample without confidential information can help investigate.
