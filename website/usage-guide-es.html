Guía de uso de microProject

Esta guía explica las operaciones básicas de la tabla de tareas, el diagrama de Gantt y CCPM en Windows. Los paquetes para Linux x64 y macOS Apple Silicon están previstos para futuras versiones. La compatibilidad total con Microsoft Project es un objetivo de desarrollo; no se garantiza para todas las operaciones y formatos.

1. Descargar, iniciar y guardar

  1. Elige la versión estable más reciente en la página de descargas. Ejecuta el instalador MSI o descomprime el ZIP portátil y abre microProject.cmd (o microProject.exe). Java está incluido.
  2. Pulsa Ctrl+N para crear un proyecto y definir su nombre y fecha de inicio. Abre proyectos existentes con Ctrl+O.
  3. Guarda con Ctrl+S. Elige .mpo (MPOF) para conservar la configuración e historial de CCPM. El formato .pod no guarda las extensiones de CCPM.
  4. Prueba primero con una copia o un proyecto de ejemplo y vuelve a abrir el archivo guardado para comprobarlo.

Abre archivos MPP, XML, POD y otros desde el comando Abrir. La compatibilidad de importación y exportación depende del formato; conserva una copia del archivo original.

2. Crear un plan en la tabla de tareas

  1. En la tabla a la izquierda del Gantt, edita la celda de nombre de una fila vacía. Usa Insert para insertar una fila y F2 para editar una celda.
  2. Introduce la duración, por ejemplo 2d. Las fechas se calculan según dependencias, calendarios laborables y restricciones. Una duración cero crea un hito.
  3. Selecciona filas y pulsa Alt+Shift+→ para aplicar sangría; Alt+Shift+← para quitarla. Expande o contrae tareas de resumen para organizar la jerarquía.
  4. Selecciona las tareas en orden y pulsa Ctrl+F2 para vincularlas; Ctrl+Shift+F2 las desvincula. También puedes editar la columna Predecesoras. Evita dependencias circulares.
  5. Pulsa Shift+F2 para consultar fechas, restricciones, predecesoras y recursos.

Selección y edición

Selecciona filas con sus números. Ctrl+Space selecciona una fila y Shift+Space una columna. Copia y pega con Ctrl+C y Ctrl+V; rellena hacia abajo con Ctrl+D. Delete elimina; Ctrl+Delete borra el contenido. Comprueba la selección antes de actuar. Ctrl+Z deshace y Ctrl+Y rehace.

Recursos y progreso

Registra personas en la hoja de recursos y asígnalas a tareas. Actualiza el porcentaje completado entre 0 y 100%. Para reflejar un retraso, actualiza también el inicio real y la duración o el trabajo restante. Registra la fecha real de finalización para tareas completadas.

3. Revisar el calendario en el Gantt

La tabla y las barras muestran las mismas tareas. Tras editar la tabla, revisa la posición y longitud de las barras y las líneas de dependencia. Pulsa Ctrl+R para recalcular.

  1. Usa Ctrl+rueda del ratón para cambiar el zoom. Selecciona una tarea en la tabla y pulsa Ctrl+Shift+F5 para desplazarte hasta ella.
  2. Arrastra una barra para mover la tarea y su extremo para cambiar la duración. Ajusta el progreso desde la parte completada. Comprueba fechas, duración y porcentaje en la tabla.
  3. Al cambiar dependencias o duración, revisa también las tareas sucesoras. Los festivos, las restricciones y los calendarios de recursos pueden ajustar las fechas.
  4. No deduzcas el estado solo por el color. Comprueba porcentaje completado, holgura total y fechas reales. La ruta crítica considera dependencias y holgura; la cadena crítica de CCPM también considera las limitaciones de recursos.

Después de cambiar el plan, comprueba Deshacer/Rehacer y guarda como .mpo; vuelve a abrir el archivo.

4. CCPM (gestión de proyectos por cadena crítica)

CCPM considera las dependencias y la competencia por recursos limitados. Gestiona la secuencia de ejecución y las reservas de tiempo al final del proyecto y donde convergen las rutas.

Aplicar CCPM

  1. Revisa las dependencias, los recursos asignados y los calendarios laborables.
  2. Abre Proyecto → Configuración CCPM, activa CCPM y define el porcentaje del búfer del proyecto. Puedes seleccionar recursos.
  3. Pulsa Vista previa y revisa tareas modificadas o divididas, conflictos pendientes y el búfer recomendado. Si quedan conflictos, ajusta las asignaciones o la nivelación y vuelve a previsualizar.
  4. Cuando el resultado sea adecuado, pulsa Aplicar nivelación. Esta acción registra la fecha base de finalización y el búfer.
  5. Guarda como .mpo y vuelve a abrir el proyecto para verificar la línea base, las asignaciones y los retrasos de nivelación.

Interpretar la red y los búferes

  • Cadena crítica: tareas que determinan directamente la fecha de finalización tras considerar los recursos.
  • Búfer del proyecto: reserva compartida que absorbe retrasos de la cadena.
  • Búfer de alimentación: reserva para retrasos que llegan a la cadena desde rutas no críticas.

Registrar retrasos e historial

El porcentaje completado por sí solo no describe un retraso. Actualiza el inicio real y el progreso, y estima de forma realista la duración o el trabajo restante. Las fechas reales son históricas y CCPM no las mueve automáticamente.

Tras registrar retrasos, ejecuta primero la vista previa. Aplicar nivelación de inmediato puede convertir el plan retrasado en la nueva línea base. Rebaselina solo cuando sea intencionado.

Al abrir el gráfico de búfer se añade una observación. Para excluir una observación errónea de los gráficos e informes CSV/HTML, selecciónala, elige Descartar esta observación… e indica el motivo. El registro de auditoría MPOF conserva el identificador, motivo, usuario y hora. Deshacer/Rehacer y guardar/volver a abrir conservan el estado.

Después de cambiar duraciones, trabajo restante, asignaciones u opciones de nivelación, ejecuta Vista previa para actualizar el análisis.
.pod no guarda las extensiones de CCPM. Usa .mpo (MPOF) para conservar la configuración CCPM.

Atajos CCPM: Ctrl+Alt+C abre la configuración; Ctrl+Shift+N abre la red; Ctrl+Shift+K abre el estado del búfer; Ctrl+Shift+J activa o desactiva la superposición CCPM del Gantt activo. El proyecto debe permitir escritura para modificar o aplicar la configuración.

6. Solución de problemas

Las fechas no son las esperadas

Comprueba predecesoras, restricciones, calendarios, duración restante y recursos; después recalcula con Ctrl+R. En CCPM, revisa los conflictos en Vista previa.

No se guarda la configuración CCPM

Guarda el proyecto en formato .mpo. .pod no incluye las extensiones CCPM. Un proyecto de solo lectura no permite cambiar ni aplicar la configuración.

Informar de un problema

En GitHub Issues, incluye la versión, pasos para reproducirlo, resultado esperado y resultado real. Un ejemplo sin información confidencial puede ayudar.
