在一个视图中规划任务与日程。

microProject 是一款桌面项目规划工具，将分层任务表与甘特图结合在一起。您可以在同一时间线上查看日期、依赖关系、进度和分配的工作，并整理 WBS 层级、里程碑、并行任务及后续任务。

您可以在桌面应用中创建和保存项目、导入和导出文件、打印以及生成 PDF。Windows 版本提供自包含安装程序和便携 ZIP，并附带 Java 运行环境。
