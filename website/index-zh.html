在一个视图中管理计划、日程和进度。

microProject 是一款桌面项目规划应用，将分层任务表与甘特图结合在一起。您可以编辑 WBS 层级，并在同一时间线上查看日期、依赖关系、资源和进度。

它提供 Microsoft 365 风格的功能区、与 Microsoft Project 相同的快捷键、关键链（CCPM）缓冲管理、打印和 PDF 输出。安装包内置 Java 运行环境，下载后即可使用。

功能

任务表与甘特图同步

编辑 WBS 任务层级，无需切换视图即可在时间线上查看日期、链接、里程碑和进度。

日程计算

根据依赖关系、日历、约束、基线和资源分配自动重新计算日程。

关键链（CCPM）

预览并应用考虑资源的调配，查看网络图，并跟踪项目缓冲和汇入缓冲的消耗。

熟悉的 Office 风格界面

功能区、Microsoft Project 风格快捷键、撤消/恢复、打印和 PDF 输出。

文件格式

  • .mpo：原生格式和默认保存格式，可继续打开早期版本保存的文件。
  • .mpp：可打开 Microsoft Project 文件（不支持写入 MPP，请另存为 .mpo）。
  • Project XML 和 XLSX：可打开和保存。MPX：仅可打开。
  • .pod：ProjectLibre 的标准格式，可打开和保存，但不保存 CCPM 设置（请使用 .mpo）。
microProject 目前正在以净室方式开发。与 Microsoft Project 桌面版的完全兼容是尚未实现的目标，详见兼容性路线图。云服务（Project Server、Project Online、Planner）以及 VBA/COM/Office 加载项不在范围内。
