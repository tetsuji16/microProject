microProject 使用指南

本指南介绍 Windows 版任务表、甘特图和 CCPM 的基本操作。Linux x64 和 macOS Apple Silicon 版本计划在后续版本中推出。与 Microsoft Project 的完全兼容是开发目标，但不保证所有操作和文件格式均兼容。

开始使用任务表甘特图CCPM快捷键故障排除

1. 下载、启动和保存

  1. 在下载页面选择最新稳定版。运行 MSI 安装程序，或解压便携 ZIP 并启动 microProject.cmd（或 microProject.exe）。软件包已包含 Java。
  2. 按 Ctrl+N 创建项目并设置名称和开始日期。按 Ctrl+O 打开现有文件。
  3. 按 Ctrl+S 保存。选择 .mpo（MPOF）以保留 CCPM 设置和历史记录。.pod 格式不保存 CCPM 扩展数据。
  4. 首次使用时，建议先使用副本或示例项目，并重新打开保存的文件检查内容。

通过“打开”导入 MPP、XML、POD 等文件。不同格式的导入和导出支持范围不同，请另行保留原始文件副本。

2. 在任务表中制定计划

  1. 在甘特视图左侧的任务表中编辑空行的名称单元格以创建任务。按 Insert 插入行，按 F2 编辑单元格。
  2. 输入工期，例如 2d。开始和完成日期会根据依赖关系、工作日历和限制条件计算。工期为零的任务是里程碑。
  3. 选择要设为子任务的行，按 Alt+Shift+→ 增加缩进；按 Alt+Shift+← 减少缩进。展开或折叠摘要任务来整理层级。
  4. 按顺序选择任务并按 Ctrl+F2 建立链接；按 Ctrl+Shift+F2 取消链接。也可以编辑“前置任务”列。请避免循环依赖。
  5. 按 Shift+F2 查看任务日期、限制条件、前置任务和资源等信息。

选择、编辑和删除

通过行号选择行。Ctrl+Space 选择行，Shift+Space 选择列。Ctrl+C 和 Ctrl+V 用于复制粘贴，Ctrl+D 向下填充。Delete 删除所选项目；Ctrl+Delete 清除内容。操作前请确认选择范围。Ctrl+Z 撤销，Ctrl+Y 重做。

资源与进度

在资源工作表中登记人员并分配给任务。将完成百分比更新为 0 至 100%。记录延误时，除了完成百分比，也要更新实际开始日期以及剩余工期或剩余工作量。任务完成后记录实际完成日期。

3. 在甘特图中检查日程

左侧表格和右侧条形图显示相同的任务。编辑表格后，检查条形的位置、长度和依赖连线。按 Ctrl+R 重新计算。

  1. 按 Ctrl+鼠标滚轮调整缩放。若要定位任务，请在表格中选择该任务并按 Ctrl+Shift+F5。
  2. 拖动任务条可移动日程，拖动边缘可更改工期。拖动进度部分可调整完成百分比。请在表格中核对日期、工期和完成百分比。
  3. 更改依赖关系或工期后，也要检查后续任务。节假日、限制条件和资源日历可能会调整日期。
  4. 不要只根据条形颜色判断状态。请结合完成百分比、总时差和实际日期检查。关键路径考虑依赖关系及时差；CCPM 关键链还考虑资源限制。

修改计划后，请检查撤销/重做，并保存为 .mpo 后重新打开确认。

4. CCPM（关键链项目管理）

CCPM 同时考虑任务依赖关系和有限资源之间的竞争，并管理执行顺序及缓冲时间。它在项目末端和路径汇合点设置共享缓冲。

应用 CCPM

  1. 检查任务依赖关系、已分配资源和工作日历。
  2. 打开项目 → CCPM 设置，启用 CCPM 并设置项目缓冲比例，也可以选择资源。
  3. 点击预览，检查更改和拆分的任务、未解决冲突及建议的项目缓冲。若仍有冲突，请调整分配或资源平衡选项后再次预览。
  4. 确认结果合适后点击应用资源平衡。此操作会记录 CCPM 基准完成日期和缓冲量。
  5. 保存为 .mpo 并重新打开项目，确认基线、资源分配和资源平衡延迟均已保留。

理解网络图和缓冲

  • 关键链：考虑资源限制后直接决定完成日期的任务序列。
  • 项目缓冲：吸收关键链整体延误的共享时间储备。
  • 汇入缓冲：吸收非关键路径延误进入关键链的时间储备。

记录延误和缓冲历史

仅靠完成百分比无法表示延误。更新实际开始日期和进度，并在“剩余工期”或“剩余工作量”中填写合理估算。实际日期属于历史记录，不会被 CCPM 应用或重新计算自动移动。

输入延误后先运行预览。立即应用资源平衡可能会把包含延误的计划设为新基线，导致缓冲消耗难以比较。仅在确实要重新设定基线时才应用。

打开缓冲图时会将当前分析添加为观测点。若要从常规图表及 CSV/HTML 报告中排除错误点，请选中该点，选择丢弃此观测…并填写原因。MPOF 审计记录会保留观测 ID、原因、用户和时间。撤销/重做以及保存后重新打开都会保留该状态。

更改工期、剩余工期、资源分配或资源平衡选项后，请运行预览以更新分析。
.pod 格式不保存 CCPM 扩展数据。若要保留 CCPM 设置，请使用 .mpo（MPOF）。

CCPM 快捷键：Ctrl+Alt+C 打开 CCPM 设置；Ctrl+Shift+N 打开 CCPM 网络图；Ctrl+Shift+K 打开缓冲状态；Ctrl+Shift+J 切换当前甘特视图中的 CCPM 显示。只有可写项目才能更改或应用设置。

6. 故障排除

日期与预期不符

检查前置任务、限制条件、工作日历、剩余工期和资源分配，然后按 Ctrl+R 重新计算。使用 CCPM 时，请在预览中检查冲突。

CCPM 设置没有保存

请保存为 .mpo。.pod 不包含 CCPM 扩展数据。只读项目不能更改或应用设置。
