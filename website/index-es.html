Planifica tareas y fechas en una sola vista.

microProject es una aplicación de escritorio para planificar proyectos que combina una tabla jerárquica de tareas con un diagrama de Gantt. Consulta fechas, dependencias, progreso y trabajo asignado en una misma línea de tiempo. Organiza la estructura WBS y revisa hitos, tareas paralelas y sucesoras.

Crea y guarda proyectos, importa y exporta archivos, imprime y genera PDF desde la aplicación. Para Windows se ofrecen un instalador autónomo y un ZIP portátil con Java incluido.
