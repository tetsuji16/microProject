microProject プライバシーポリシー

最終更新日：2026年11月27日

集める情報

microProject は、氏名、メールアドレス、利用状況などの個人情報を集めません。利用状況の送信（テレメトリ）や広告はありません。

プロジェクトファイル

作成したプロジェクトファイルは、利用者が選んだ場所（利用者のコンピューターなど）にだけ保存されます。microProject がファイルの内容を外部に送ることはありません。

ネットワーク接続

  • Microsoft Store 版：microProject は自分からネットワークに接続しません。更新は Microsoft Store が行います。「更新の確認」を選ぶと、Microsoft Store の microProject のページを開きます。
  • GitHub で配布している版：起動時に GitHub Releases API（api.github.com）へ最新版を問い合わせます。送るのは通常の HTTPS 要求だけで、個人情報やファイルの内容は含みません。この問い合わせは、設定の「起動時にアップデートを確認」で止められます。

ヘルプやリンクを開いたときは、既定のブラウザーでそのページを開きます。その先のサイトでの情報の扱いは、そのサイトのポリシーに従います。

お問い合わせ

ご質問は GitHub の issue でお寄せください。

microProject Privacy Policy

Last updated: November 27, 2026

Information we collect

microProject does not collect personal information such as names, email addresses or usage data. It contains no telemetry and no advertising.

Project files

Project files you create are stored only where you choose to save them, such as on your own computer. microProject never sends their contents anywhere.

Network connections

  • Microsoft Store edition: microProject makes no network connections on its own. Microsoft Store handles updates. Choosing "Check for updates" opens the microProject page in Microsoft Store.
  • Edition distributed on GitHub: at startup it asks the GitHub Releases API (api.github.com) for the latest version. This is a plain HTTPS request that contains no personal information or file contents. You can turn it off with the "Check for updates at startup" setting.

When you open help or a link, it opens in your default browser. How the destination site handles information is governed by that site's own policy.

Contact

Please send questions through GitHub issues.
