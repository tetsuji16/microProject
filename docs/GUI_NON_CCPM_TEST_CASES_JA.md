# 非CCPM GUI網羅テストケース（14件）

CCPM機能を使わず、通常のプロジェクト編集GUIを検証する。全ケースでmicroProjectを最大化し、画面証跡はmicroProjectウィンドウだけを対象とする。

| ID | シナリオ | 主なマウス操作 | 期待結果 |
|---|---|---|---|
| GUI-NC-01 | 起動・ウェルカム画面 | 起動後に更新／復旧ダイアログを閉じ、ウェルカム画面を操作 | microProjectが応答し、新規作成へ進める |
| GUI-NC-02 | 新規プロジェクト | **ファイル > 新規**、名前入力、OK | 空のタスク表とガント領域が表示される |
| GUI-NC-03 | タスク追加・編集 | 名前セルをクリック、文字入力、Insertで行追加 | 行番号とタスク名が正しく表示される |
| GUI-NC-04 | 期間・日付編集 | 期間、開始日、終了日のセルをクリックして入力 | 入力値が保持され、ガントバーが更新される |
| GUI-NC-05 | 依存関係編集 | 先行列へタスクIDを入力し、別セルをクリック | 先行値が表示され、ガントに矢印が出る |
| GUI-NC-06 | リソース作成・割当 | リソースタブで担当者を作成し、タスクへ割当 | リソース名と割当状態が表に反映される |
| GUI-NC-07 | カレンダー変更 | プロジェクトタブのカレンダーを開き、非稼働日を設定 | ガントの日付計算が変更され、設定が保持される |
| GUI-NC-08 | 表示切替・選択 | ビュー／ガント表示を切替、行選択、スクロール | 選択行とガントの対応が崩れず、再描画される |
| GUI-NC-09 | 保存・再読込 | **名前を付けて保存**で`.mpo`保存、閉じて再度開く | タスク、期間、依存関係、リソースが保持される |
| GUI-NC-10 | 入力エラー回復 | 不正日付・不正先行を入力し、エラーを閉じて正しい値を再入力 | 明示的エラーで停止し、既存データを破壊せず復旧できる |
| GUI-NC-11 | 複数プロジェクト読込 | 最近使ったプロジェクトまたは開く操作で2つ以上の`.mpo`を順番に開く | 各プロジェクトのタイトル・タスク内容が混在せず、切替後も個別状態が保持される |
| GUI-NC-12 | タスク表テキスト入力 | タスク名・メモ等のテキストセルをクリックし、日本語・長文・空文字を入力 | 入力文字が対象セルだけに保持され、隣接セルや行が意図せず変更されない |
| GUI-NC-13 | 表／ガントからの日付変更 | 先行／後続タスクの開始日・終了日をタスク表で変更し、ガントバーをドラッグして別タスクの日付も変更 | 変更したタスクと依存する後続／先行タスクの日付・バー・矢印が再計算され、一致する |
| GUI-NC-14 | MSP仕様の日付連動 | FS/SS/FFなどの依存関係を持つタスクを表セルまたはガントバーで移動する | MSP仕様と同じ制約（ラグ・カレンダー・手動スケジュールを含む）で関連タスクだけが連動し、無関係なタスクは移動しない |

## 検証順序

GUI-NC-01〜02でプロジェクトを準備し、03〜08を同一プロジェクトで実施する。09で保存・再読込を行い、10を最後に実施する。各ケースは、模擬GUIテスト後に実マウス操作で再確認する。

## 合否基準

- マウスクリック対象とキーボード入力対象が一致し、フォーカス移動で別セルを誤更新しない。
- 入力後のタスク表・ガント・リソース表示が同じモデル状態を示す。
- 保存・再読込後に編集内容が失われない。
- 不正入力は明示的に拒否され、プロジェクトが破損しない。
- デスクトップ、タスクバー、他アプリを含む画面キャプチャは証跡に使用しない。

## 実施記録（2026-08-30）

- GUI-NC-12は`TaskTextInputGuiAcceptanceTest`で実Robot操作を実施。タスク名セルをマウスクリック後、F2編集経路で空文字・null相当・日本語を含む長文を入力し、対象タスクだけが更新され隣接タスク（Untouched）が変更されないことを確認した。
- 実行コマンド: `.\gradlew.bat :micrproject_ui:guiTest --tests "com.microproject.pm.graphic.spreadsheet.TaskTextInputGuiAcceptanceTest" --console=plain`（BUILD SUCCESSFUL、3ケース）。
- GUI-NC-10は`TaskDateDependencyGuiAcceptanceTest`で不正日付（`not-a-date`）を実Robot入力。警告ダイアログの表示を検出し、編集をキャンセルして元の日付を保持することを確認した（テスト内でクライアントモードを明示してダイアログを安全に閉じる）。
- 同ケースで不正な先行タスクID（`999999`）も実Robot入力し、エラーダイアログ、既存リンク保持、編集終了を確認した。
- GUI-NC-07は`ChangeWorkingTimeDialogGuiAcceptanceTest`で実Robotによる稼働時間ダイアログ表示、日付セル選択、非稼働ラジオボタン、OK保存、Cancel操作を確認した。選択日が保存後に非稼働となること、Cancel時にコミットされないことを確認した。
- 追加調査で、scratch copyを対象に編集可否を判定していたためプロジェクトカレンダーのラジオボタンが無効化される不具合と、`updateWorkingHours()`が編集フラグを消去する不具合を修正した。修正後は実Robot日付保存ケースを含むfocused/full GUIスイートが成功した。
- GUI-NC-11は`DefaultFrameManagerGuiAcceptanceTest`で2つのプロジェクトフレームを実ウィンドウに表示し、プロジェクト選択コンボをマウスクリック＋キー入力で切り替えた。選択後に対象フレームだけが表示・activeとなり、他方のフレームと状態が混在しないことを確認した。
- GUI-NC-13/14のガント操作は`GanttBarDateDragGuiAcceptanceTest`でFS/SS/FF/SF依存を実Robot検証した。先行バーを2日分ドラッグ後、FS/SS/SFでは依存計算に基づく後続開始日、FFでは後続終了日が制約と一致することを確認した。
