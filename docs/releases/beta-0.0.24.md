# microProject 0.0.24 beta

Windows 用の計画作成・更新・CCPM運用を対象にしたベータ版です。MSI または ZIP を GitHub の prerelease から取得できます。Windows ゲートに合格するまで配布物を公開しません。

## 最小実用範囲

- タスク表：名前・期間・日付・進捗の編集、行の追加・削除、階層化、依存関係、Undo/Redo。
- ガント：表とバーの連動、日付／期間の変更、ズーム・スクロール、依存関係の表示。
- CCPM：設定・適用、クリティカルチェーン／バッファの表示、Undo/Redo、MPO 保存・再読込。
- 新規作成、MPO 保存・再読込、既存 POD と MPP の読込。

## この版の修正

起動時のウィンドウ例外、File コマンドの状態登録、MPP 割当読込時の異常な期間、MPO タスク ID の衝突・共有プール参照、一時ファイルの所有者判定を修正しました。CCPM をクリアした後の Undo で監視履歴と撤回記録が失われる不具合も修正しました。リソース置換ダイアログを割当ダイアログの子にし、閉じた後にキーボード操作を続けられるよう修正しました。空行を挟む計画の保存時にタスク ID の対応がずれ、MPO 再読込が失敗する問題を修正しました。

## 検証と配布

全モジュールの回帰、実 Robot smoke、配布物の MPP/POD 読込、Windows EXE 起動、配布 JAR の一致を公開前に検証します。MSI、ポータブル ZIP、SHA256SUMS、リリースノートを配布します。

このベータは安定版の latest と自動更新 manifest を更新しません。ベータ用 EXE は自動更新を無効にし、安定版の更新でベータの JAR が置き換わることを防ぎます。全 MSP 機能との互換性、すべてのダイアログ／locale／DPI の保証は本ベータの範囲外です。広い GUI 監査は週次 full suite に残しています。大切な計画は元ファイルを保管し、コピーでベータを評価してください。

不具合報告には版、Windows/DPI/言語、再現手順、期待結果、匿名化した MPO、ログを添付してください。保存内容の欠落、タスク表とガントの不一致、Undo 不成立、予期しないエラー画面は次版の優先修正対象です。
