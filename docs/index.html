Desktop Project Planning

タスク表と Gantt を、ひとつの計画画面に。

microProject は、階層化したタスク表と Gantt チャートを並べて扱う Windows 向けのデスクトップ計画ツールです。 工程の開始日・終了日、依存関係、進捗、担当作業を、同じタイムラインで確認できます。

表のアウトラインで WBS を整理しながら、右側の Gantt でマイルストーン、並行作業、後続タスクへのつながりを確認できます。 建設・開発・イベントなど、複数の工程を持つ計画を見通しよく管理できます。

作成・保存に加え、インポート、エクスポート、印刷、PDF 出力をデスクトップ画面から利用できます。 Windows 向けの配布は、自己完結型の MSI と Portable ZIP を用意しています。

Why This Fork

工程の全体像と、日々の更新をつなげる。

タスク表と Gantt を同期

WBS 形式のタスク階層を編集すると、対応する工程を Gantt 上で確認できます。表とタイムラインを行き来せずに、計画の構造と日程を見比べられます。

依存関係と進捗を見える化

後続タスクへのつながり、マイルストーン、並行する作業をタイムラインに表示し、工程の順序と進み具合を把握しやすくします。

ファイルをやりとりしやすく

デスクトップ画面からプロジェクトを作成・保存し、インポート、エクスポート、印刷、PDF 出力へ進めます。Windows では MSI または Portable ZIP を選べます。

GitHub Pages は GitHub Releases 上の配布物を案内し、リポジトリ内でバイナリを直接配らない方針です。
