この fork の主な改善点

ここで挙げている改善点は、ProjectLibre 1.9.8 系の更新コミット 0530be22 を基準にした差分です。

  • XLSX import / export に対応し、Excel ベースの受け渡しを扱いやすくしました。
  • 共有プロジェクトファイルを前提にしたローカル共同編集フローを追加しました。
  • Gantt / Tracking Gantt の progress line 表示を修正し、進捗可視化を改善しました。
  • Gantt zoom の復元処理を追加し、再表示時の見え方の一貫性を上げました。
  • task view のマウスホイール挙動を見直し、Shift+wheel の横スクロールにも対応しました。
  • 起動直後や初期ビュー読み込みまわりの安定性を改善しました。
  • 新しい JDK と jpackage を使った Windows 向けパッケージングに更新しました。

アプリ概要

ProjectLibre は WBS、Gantt、依存関係、進捗、リソース配分を扱えるデスクトップ型のプロジェクト計画ツールです。この fork では、元のコードベースを保ちながら、現代的な Java 環境で継続利用しやすいように更新しています。
