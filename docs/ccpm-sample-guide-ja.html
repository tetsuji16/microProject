20タスクCCPMサンプルの使い方

一般的なシステム導入プロジェクトを題材に、依存関係、クリティカルチェーン、プロジェクト・バッファを確認するための短い実習です。2026年8月末時点を想定し、完了済み・進行中・未着手の作業を混在させています。CCPM設定は有効ですが、ベースラインは未作成です。

サンプル（.mpo）をダウンロード 履歴付きサンプル CCPMの基本説明へ戻る
このページはスクリーンショットを使用していません。したがって、デスクトップ、スタートバー、またはmicroProject以外のアプリケーション画面は掲載していません。

サンプルに含まれる構成

タスク数は20件です。単純な一本道ではなく、設計・実装・テスト・運用準備が合流する、日常的なプロジェクト構成にしています。進捗は完了11件、進行中4件、未着手5件で、達成率は0%、20%、40%、65%、75%、100%を含みます。

主経路: プロジェクト開始 → 現状ヒアリング → 要件定義 → 要件レビュー → 基本設計 → アーキテクチャレビュー → 基幹機能の実装 → 単体テスト → 結合テスト → システムテスト → 利用部門受入テスト → 本番リリース → プロジェクト完了

CCPMを適用して確認する

  1. ダウンロードした CCPM 標準システム導入 20タスク.mpo をmicroProjectのファイル → 開くで開きます。
  2. タスク表の先行列と達成率列を確認します。開始時点なので、全20タスクの達成率は 0% です。
  3. プロジェクト → CCPM 設定を開き、CCPMが有効になっていることを確認します。必要ならプロジェクトバッファの割合を調整します。
  4. プレビューを実行します。候補のクリティカルチェーン、競合、プロジェクト・バッファ、フィーディングバッファを確認します。プレビューだけでは予定は変更されません。
  5. 内容を確認して平準化を適用します。これでCCPMのベースラインが作成されます。
  6. Ctrl+Shift+NでCCPM ネットワーク、Ctrl+Shift+KでCCPM バッファ状況を開きます。

リソース競合も試す場合

このサンプルは依存関係の確認を優先し、初期状態ではリソースを割り当てていません。CCPMのリソース平準化も試すには、同じ担当者を「基幹機能の実装」と「画面機能の実装」に100%で割り当て、対象リソースを選んでプレビューしてから適用してください。適用時の対象範囲は .mpo に保存され、再読込後のネットワーク図・バッファ状況も同じ範囲で再分析されます。

困ったとき

ネットワーク図が表示されない場合は、先にCCPM設定で平準化を適用してベースラインを作成してください。CCPMをクリアした場合は、ベースラインと画面上のバッファ履歴の両方が消去されます。CCPMの設定やベースラインを保持する用途では、従来形式の .pod ではなく .mpo で保存します。

バッファ遷移を試す実習

同じmicroProjectセッション内では、バッファ状況を開くたびに観測点が保持されます。次の手順で、0% / 0% からプロジェクトを右方向へ進め、週次の見積り更新に応じてバッファが小さく変動する、通常の導入プロジェクトらしい軌跡を確認できます。

  1. サンプルは新規プロジェクト時点の 0% で始まります。CCPMを適用して Ctrl+Shift+K を開くと、最初の観測点は0% / 0%です。
  2. 最初の週次更新として、完了済み・進行中の作業を反映してプロジェクト達成率を約25%に更新します。「プロジェクト完了」の期間を 1d から 2d に変更し、結合確認に1日余分にかかる見込みを記録します。グラフに約22% / 27%の点が追加されます。
  3. 中間レビューで達成率を約50%に更新します。関係者確認がさらに1日必要と判明した想定で、同タスクの期間を 3d に変更します。約45% / 55%まで上がり、注意領域へ入ります。
  4. 対策後の週次更新では達成率を約75%に進め、確認方法の見直しで期間見積りを 2d に戻します。約69% / 27%へ下がり、進捗は右へ進みながら安全領域へ回復します。

観測点の履歴は現行MPOFの ccpm/history.jsonl に保存されます。保存後にファイルを閉じて再度開くと、保存前のグラフを復元できます。

保存・再読込と週次レポート

  1. 各更新後に名前を付けて保存で`.mpo`へ保存します。保存時点の日時、担当者、進捗率、バッファ消費率、ゾーンが履歴に追加されます。
  2. ファイルを閉じて再度開き、Ctrl+Shift+Kでバッファ状況を表示します。保存前の観測点が時系列で復元されます。
  3. 週次レポートでは、週初・週末の進捗と消費率、GREEN／AMBER／REDの遷移、最終更新者を確認します。CSV／HTML出力を会議資料に利用できます。
