CCPM（Critical Chain Project Management）は、依存関係に加えて共有リソースの競合を考慮する計画手法です。microProjectでは、CCPMの設定、適用、ネットワーク、バッファ状況を使って計画を管理できます。

CCPMを試す前に、練習用MPOのコピーを作り、タスク期間、依存関係、リソース割当、進捗を整えます。競合する割当がなければ、リソースを考慮したチェーンを比較する材料がありません。

## 設定と適用

![CCPM設定画面。対象タスクがない初期状態で、平準化・CCPMネットワーク・バッファ消費状況のタブと、プレビュー・平準化を適用ボタンの位置を示す（英語表示で撮影）](figures/ch08-ccpm-settings.png)

次の順で操作します。

1. 「プロジェクト」タブを開き、「CCPM 設定」をクリックします。設定画面で **クリティカルチェーン・プロジェクト管理（CCPM）を使用する** をオンにし、**プロジェクトバッファ** の割合を確認します。
2. **プレビュー** をクリックし、変更対象タスク、日程、チェーン、競合、バッファを確認します。計画の前提と合わなければ適用せず、入力や設定を見直して再度 **プレビュー** をクリックします。
3. 採用する場合だけ **平準化を適用** をクリックし、タスク表とガントの日程を確認します。
4. 「ビュー」タブの「クリティカル チェーン」をクリックし、チェーンとタスクのつながりを確認します。
5. 「レポート」タブの「CCPM バッファ状況」をクリックし、進捗とバッファ消費を確認します。

設定画面上部の **CCPM ネットワーク** と **バッファ消費状況** のタブ、および「ビュー」「レポート」タブのコマンドは、計画に対する結果の確認に使います。

## バッファを週次確認する

実績を更新した後にバッファ状況を開き、前回からの変化と、「安全」「注意」「対策が必要」のどの区分にあるかを確認します。色だけで判断せず、遅れているタスク、残存期間、担当リソースをネットワークとタスク表で照合します。必要な対策、担当、期限を会議で決めます。

「レポート」タブの「CCPM バッファ状況」からCSVを出力できます。ファイルを開き、列と値を画面に照合してください。CCPM情報を保つ運用ではMPOを使い、保存後に再度開いて設定・基準・履歴を確認します。PODはProjectLibreの標準形式で、CCPMの設定を保存できません。

## この章のまとめ

- 入力（依存、期間、割当、実績）を整えてからプレビューします。
- 適用後はガント、CCPMネットワーク、バッファ状況をそれぞれ確認します。
- Undo／RedoとMPO再読込を確認し、バッファを具体的な対策に結び付けます。

:::exercise プレビューをレビューする
コピーした計画でCCPM設定を開き、プレビュー結果の変更タスク、日程、競合を読みます。適用した場合はネットワークとバッファ状況を確認し、Undo／Redo後にMPOを再読込します。
:::answer
適用前後のタスク・日程とバッファを照合し、計画の意図に合う結果になったことを確認します。
:::
