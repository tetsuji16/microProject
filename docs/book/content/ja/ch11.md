ビューはデータを違う角度から見せます。フィルターは対象を絞り、グループは共通項でまとめ、並べ替えは順序を変えます。どれも見たい情報へ近づくための操作ですが、並べ替えだけはタスクの順序とIDを変える使い方もあるため、表示の変更とデータの変更を区別して使います。

この章を終えると、次のことができるようになります。

- フィルターで対象のタスクを絞り込み、解除して元に戻せる
- グループで完了・未完了などの区分ごとにタスクをまとめられる
- 表示だけの並べ替えと、IDを振り直す並べ替えを区別できる

## フィルターで対象を絞る

1. ガントビューのタスク表を表示します。
2. 「ビュー」タブの「データ」グループで **フィルター** をクリックし、一覧から条件を選びます。たとえば **完了していないタスク**、**クリティカル タスク**、**マイルストーン** などがあります。
3. 表示された行が条件に合っているか、ガントのバーが同じ行に並んでいるかを確認します。
4. 確認が終わったら、同じ一覧で **フィルターなし** を選び、非表示だった行が戻ったことを確かめます。

フィルターは行を隠すだけで、タスクを削除しません。行が減って見えるときは、まずフィルターが掛かっていないかを確認します。報告に使う場合は、どの条件で絞ったかも書き添えます。

## グループでまとめる

1. 「ビュー」タブの **グループ** をクリックし、**完了/未完了** や **クリティカル** などの区分を選びます。
2. タスク表が区分ごとの見出しで分かれたことを確認します。
3. 元の表示に戻すときは **グループなし** を選びます。

グループは見出しで行をまとめる表示の操作です。サマリータスクとの親子関係（第2章）とは別のものなので、グループの見出しをWBSの階層と取り違えないようにします。

## 並べ替えで順序を整える

1. 「ビュー」タブの **並べ替え** をクリックし、並べ替えのキーを選びます。必要に応じて **次の並べ替え** を追加します。
2. 表示順だけを変える場合は、タスクのIDとアウトライン構造が保たれていることを確認します。
3. **タスクを並べ替えて ID を振り直す** を選ぶと、プロジェクト内のタスク順とIDが変わります。確認メッセージを読んでから実行し、IDが新しい順序で振り直されたことを確かめます。

IDを振り直す並べ替えは計画データの変更です。実行前に計画を保存してコピーを取り、練習用のコピーで結果を確かめてから本番の計画に適用します。

:::trap 絞り込んだまま保存して共有する
フィルターやグループを掛けたまま画面を見せると、受け取った人は一部のタスクだけを全体だと誤解することがあります。共有や報告の前に、表示条件を解除するか、条件を明記します。
:::

## この章のまとめ

- フィルターは対象を絞り、グループは区分でまとめ、並べ替えは順序を変えます。
- フィルターとグループは表示の操作で、解除すれば元の表示に戻ります。
- IDを振り直す並べ替えはデータを変えるため、実行前にコピーを取り、結果のIDと順序を確認します。

:::quiz
Q: フィルターを掛けたら行が減りました。タスクは削除されていますか。
A: いいえ。条件に合わない行が非表示になっただけです。**フィルターなし** を選ぶと戻ります。
Q: グループの見出しとサマリータスクは同じものですか。
A: いいえ。グループは表示上のまとまりで、サマリータスクはWBSの親子関係です。
:::

:::exercise 未完了の作業を洗い出す
練習計画のコピーを開き、**完了していないタスク** のフィルターで対象を絞ります。次に **完了/未完了** でグループ化し、区分ごとの行数を記録します。最後にフィルターとグループを解除し、すべての行が戻ったことを確認します。
:::answer
フィルター適用中は完了済みのタスクが非表示になり、解除するとすべての行が戻ります。グループ化では完了・未完了の見出しの下にタスクが分かれます。どちらもタスクのIDや先行タスク列は変わりません。
:::
