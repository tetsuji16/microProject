## Implementation

- `IconManager.getIcon()` preserves SVG painting rather than making a 16px raster. Existing 16px SVG contracts remain; same-name raster companions at or below 16px preserve their native dimensions (9px tree controls).
- `getHalfSizedIcon()` derives SVG dimensions without rasterizing. PNG/GIF fallback behavior remains.
- Added SVG companions for 9 task-status assets, 7 resource/team assets, and plus/minus tree glyphs. Original raster files and mappings remain unchanged.
- Tests share fixed-raster negative controls, source mapping/dimension checks, visible bounds and semantic colors. Tree SVGs match the original 9px opaque/transparent pixels at 100%.
- No production callers cast these icon images to BufferedImage. Window/cursor image consumers and ImageIcon wrappers remain compatible.
