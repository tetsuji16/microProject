# CCPM GUI網羅テストケース（14件）

対象はWindows上のmicroProjectです。全ケースでmicroProjectを最大化し、スクリーンショットはアプリウィンドウだけを対象にします。デスクトップ、タスクバー、他アプリが見える場合は証跡として採用しません。

## テストケース一覧

| ID | シナリオ | GUI操作 | 期待結果 | 判定 |
|---|---|---|---|---|
| CCPM-GUI-01 | 起動と初期画面 | クリーンな配布物を起動し、更新・復旧ダイアログを処理する | microProjectの開始画面が表示され、他アプリを操作せずに新規作成へ進める | 実GUI確認済み |
| CCPM-GUI-02 | 新規プロジェクト | **ファイル > 新規**、プロジェクト名入力、OK | 空のタスク表が表示され、タイトルに入力名が表示される | 実GUI確認済み |
| CCPM-GUI-03 | 連続タスク入力 | Insertで10行追加し、名前と期間を入力する | 行番号、名前、期間が保持され、ガントバーが表示される | 実GUI確認済み |
| CCPM-GUI-04 | 先行関係 | 2行目以降の「先行」に直前タスクIDを入力する | 先行IDが数値として表示され、ガントに矢印が連続して表示される | 実GUI確認済み |
| CCPM-GUI-05 | 独立タスク | 先行を空欄にしたタスクを10行追加する | 独立タスクが作成され、連続タスクとは別ノードとして扱われる | 実GUI確認済み |
| CCPM-GUI-06 | リソース割当 | リソース画面で担当者を作成し、複数タスクへ割り当てる | リソース名がタスク表に表示され、同一リソースの競合が検出対象になる | GUI受入済み（ResourceLevelingDialogGuiAcceptanceTest） |
| CCPM-GUI-07 | CCPMプレビュー | **プロジェクト > CCPM設定**、CCPMを有効化、**プレビュー** | 変更候補・競合・推奨バッファが表示され、適用前の予定は確定変更されない | 実GUI確認済み |
| CCPM-GUI-08 | CCPM適用 | プレビュー内容を確認し、**平準化を適用**、閉じる | 平準化後の開始日・終了日とCCPMベースラインが作成される | 実GUI確認済み |
| CCPM-GUI-09 | グラフ表示 | `Ctrl+Shift+N`でネットワーク、`Ctrl+Shift+K`でバッファ状況を開く | 連続タスクは矢印で接続され、独立タスクも表示される。バッファグラフが描画される | 実GUI確認済み |
| CCPM-GUI-10 | 保存・再読込と異常入力 | `.mpo`で保存、閉じて再読込する。先行列へ不正文字も入力する | タスク・依存関係・CCPM状態が維持される。不正先行は明示エラーとなり、破損保存しない | 実GUI確認済み |
| CCPM-GUI-11 | 複数プロジェクト読込 | 最近使ったプロジェクトまたは開く操作で複数の`.mpo`を順番に開く | 各プロジェクトのタスク、依存関係、CCPM状態が混在せず、切替後も保持される | 実GUI確認済み |
| CCPM-GUI-12 | タスク表テキスト入力 | タスク名・メモ等のテキストセルへ日本語・長文・空文字を入力する | 対象セルだけが更新され、隣接セル・依存関係・ガント表示が不意に変更されない | 実GUI確認済み |
| CCPM-GUI-13 | 表／ガントの日付変更 | 先行／後続タスクの日付を表セルで変更し、ガントバーをドラッグして別タスクの日付も変更する | 依存する先行／後続タスクの日付、バー、矢印、CCPM計算が再描画され整合する | 実GUI確認済み |
| CCPM-GUI-14 | MSP仕様の日付連動 | FS/SS/FFなどの依存関係を持つタスクを表セルまたはガントバーで移動する | MSP仕様と同じ制約（ラグ・カレンダー・手動スケジュールを含む）で関連タスクだけが連動し、無関係なタスクは移動しない | ProjectLibre実GUI確認済み、MS Project直接比較は環境待ち |

## 実施順序と証跡

1. CCPM-GUI-01〜02で新規プロジェクトを準備する。
2. CCPM-GUI-03〜06で、連続10タスク＋独立10タスクを作成する。
3. CCPM-GUI-07〜08でプレビューと平準化適用を確認する。
4. CCPM-GUI-09でネットワークとバッファ状況を確認する。
5. CCPM-GUI-10で`.mpo`保存・再読込と不正入力時のエラー処理を確認する。
6. 各ケースについて、操作結果、画面状態、再現条件、スクリーンショット（microProjectのみ）をissueへ追記する。
7. CCPM-GUI-11〜14は、保存済みプロジェクトを2つ以上用意し、プロジェクト切替・文字入力・依存関係の日付変更・MSP仕様との比較を実施する。

## 合否基準

- 画面遷移・入力・ダイアログがハングせず完了する。
- 連続タスクの先行ID、独立タスクの空欄が意図どおり保持される。
- CCPM適用後にネットワークとバッファグラフが空白にならない。
- 保存・再読込後もタスク、依存関係、CCPMベースラインが維持される。
- 不正入力は明示的に拒否され、元のプロジェクトデータを壊さない。
- 証跡画像にmicroProject以外の画面要素を含めない。
