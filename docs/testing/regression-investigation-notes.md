re-investigate incorrectly. It supplements the live acceptance rules in
[`TEST_PLAN.md`](../../TEST_PLAN.md), [`gui-quality-gate.md`](../gui-quality-gate.md),
and [`gui-recovery-sequence.md`](../gui-recovery-sequence.md); it does not replace
their gates. Recheck the cited source, test, and run when the implementation or
fixture changes. Keep confirmed causes separate from hypotheses.
